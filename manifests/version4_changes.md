# Manuscript version 4 changes

Only two scientific red-line corrections were made relative to manuscript version 3:

1. I-SPY2 is described as an **independent cohort-level workflow evaluation**, not as independent validation of every signature. This preserves the registry's documented I-SPY2 overlap status for benchmark/control signatures such as TIS18, Chemokine12, GeparSixto12 and TLS_ST30.
2. The main text explicitly discloses the **six-module pre-freeze pCR feasibility screen**. That feasibility screen is excluded from confirmatory claims and did not determine membership of the 23-signature registry.

No Results section was restructured and no new scientific analysis was added in version 4.
